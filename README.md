# Business Management System

A simple Business Management System developed using basic Python. This project helps manage products, inventory, sales, and expenses through a menu-driven program.

## Features
- Add new products
- View product inventory
- Record sales
- Automatically update stock after sales
- Add business expenses
- Generate business reports

## Technologies Used
- Python 3
- Lists and Dictionaries
- Functions
- Loops
- Conditional Statements

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/Business-Management-System.git
   ```

2. Open the project folder:
   ```bash
   cd Business-Management-System
   ```

3. Run the program:
   ```bash
   python business.py
   ```

## Project Objective

The objective of this project is to understand and implement basic Python programming concepts by creating a practical business management application.

## Limitations
- Data is stored temporarily in lists.
- Data is lost when the program exits.
- Profit calculation does not include product purchase costs.
